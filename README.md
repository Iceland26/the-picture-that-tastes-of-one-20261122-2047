One picture of food, one ingredient: **a single ripe strawberry** — close-up on a
matte white plate, deep red gradient, seed dimples, glossy juice droplets, soft
top light. Procedurally rendered in pure Python (stdlib only, deterministic).

## Run

```sh
python3 main.py
```

Writes `/output/entry.png` (960×960 PNG, ≤ 1 MiB).
